# AWS IAM & EC2 — Module 02

A beginner-friendly static website explaining the Module 02 topics from the Codomax Digital Solutions internship task.

## Files
- `index.html` — website content
- `style.css` — responsive styling

## Run on a phone
1. Download and extract this ZIP.
2. Open the folder in TrebEdit or another HTML editor.
3. Open `index.html` in the preview/browser.
4. Keep `index.html` and `style.css` in the same folder.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `aws-iam-ec2-module-02`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the website URL shown in the Pages section.

## AWS learning checklist (perform in your own AWS account only if authorized)
- Review IAM users, groups, roles, policies, and permissions.
- Apply least privilege; do not share root credentials or access keys.
- Review EC2 launch settings and security group concepts.
- Do not open unnecessary inbound ports or expose credentials.
- Check AWS pricing and free-tier eligibility before creating resources. Stop/terminate resources when finished to avoid unexpected charges.

## Important
This repository contains an educational static website. It does **not** provision AWS resources, launch an EC2 instance, configure an IAM account, or prove a live EC2 deployment. Only describe those practical tasks as completed after you have actually performed and verified them.
