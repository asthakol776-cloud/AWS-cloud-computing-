AWS IAM & EC2

Understanding access management, cloud security, and virtual servers on Amazon Web Services.

Explore the concepts

CORE CONCEPTS

What I learned

👤

IAM Users

An IAM user represents a person or application that needs access to AWS resources.

👥

Groups & Roles

Groups organize users. Roles provide temporary permissions to trusted users or services.

📜

Policies

Policies are permission documents that define which actions are allowed or denied.

🖥️

Amazon EC2

EC2 provides resizable virtual servers, called instances, in the AWS cloud.

🛡️

Security Groups

Security groups act as virtual firewalls and control inbound and outbound traffic.

🌐

Web Server

A web server can host a basic HTML website on an EC2 instance.

IMPORTANT SECURITY PRINCIPLE

Least Privilege

Give each user, role, or application only the permissions required to perform its task—and no more. Review permissions regularly.

✓

SIMPLE WORKFLOW

How the pieces work together

01IAM controls who can access AWS resources.
02EC2 runs the application on a virtual server.
03A security group controls permitted network traffic.
04A web server delivers the HTML page to visitors.
